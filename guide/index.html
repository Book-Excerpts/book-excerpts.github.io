          # 介绍

          # 『摛藻』之名。

          摛藻（chī zǎo），铺陈辞藻，意谓施展文才。出自 苏轼《书太宗御书后》：

          “天纵之能，溢於笔墨，『摛藻』尺素之上，弄翰团扇之中。”

          摛藻的主题色是 #bc343c(象牙紅) 和 #eee1ca(乳白色)；色卡：中国传统颜色 | Frank inDev. (opens new window)。

          # 摛藻是...？

          『摛藻』是一个由原生 JS 开发的文学项目，目前已经在GitHub (opens new window)开源，网站当前提供 一句话服务 以及 自定义上传一句话服务。在这一点有些像一言-Hitokoto (opens new window)。

          # 它是如何工作的？

          『摛藻』核心部分由三部分构成：第一部分是选择器，用于请求外部配置API中的信息，从而选择正确的函数，使插件正确工作；第二部分是请求API，它包含一个JS内置对象，工作时，先获取选择器指定函数的参数及函数值，生成正确的数据；第三部分是导出API，它包含一个HTML DOM对象，用于将请求API获取的数据打印在HTML中指定的容器中。

          # 一言-Hitokoto

          老实说，摛藻早期的创作灵感确实来自于 一言，首先感谢一言为我们的开发提供了灵感，同时也不得不承认，一言的功能确实比摛藻更加全面，技术也更加成熟。但是，相对来说，『摛藻』的调用及部署门槛要更低一些（v1本体），首先，你不需要一台动态服务器作为部署『摛藻』的基础，基于原生 JS 的特性，使用静态的云端空间即可，在数据量较小的情况下，『摛藻』能够胜任一些场景下的任务。
