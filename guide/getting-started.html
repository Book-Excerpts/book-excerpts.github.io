    # 快速上手

    WARNING

    ** 前提条件 ** 请确保您的服务器已经开启 CORS（跨域资源共享）以消除非同源限制对调用插件的不良影响。

    本文会帮助你从头配置『摛藻』，具体包括『摛藻』的安装、使用。

    # 安装

    目前您可以通过 jsDelivr 进行安装。

    • 通过 jsDelivr 安装
    <script src="https://cdn.jsdelivr.net/gh/ChizaoProject/chizaobook@latest/app.js"></script>

    # 使用

    首先，您需要在页面添加一个容器：

    <chizaobook>

    之后使用以下JavaScript代码来生成插件：

    const chizaobook = new Chizaobook({
	container: "chizaobook", // string
	packageSource: "", // string
	packageType: 8 // int
});

    # container 参数配置

    container 参数用来定义容器，从而让插件知道在何处生成信息。

    容器的选定基于构造函数，生成信息到容器的操作基于HTML的内置方法getElmentsByTagName()。

    WARNING

    注意：与其它插件的容器引入方式不同，『摛藻』的容器是一个HTML标签，而非<div>标签中的一个ID属性。因此，在配置时不应写成<div id="chizaobook"></div>的形式。

    # packageSource 参数配置

    packageSource: "", // string

    packageSource 参数用来引入“数据包”或“数据包索引”，二者都是JSON文件，程序会根据引入的JSON数据自动判断其所请求的数据是前者还是后者。

    在快速配置阶段（此处），我们建议直接填入官方的数据包索引：https://cdn.jsdelivr.net/gh/ChizaoProject/Packages@latest/package_source.json

    但是，为了满足用户的个性化需求，我们允许用户自定义数据包和数据包索引，关于如何定义它们，请浏览配置第三方数据包及数据包索引。

    # packageType 参数配置

    packageType 用来描述数据包的类型。
